# Back to Leaf - Teacher Demo

This folder is ready for GitHub Pages.

## Upload Steps

1. Create a new public GitHub repository, for example `back-to-leaf-demo`.
2. Upload `index.html` from this folder to the repository root.
3. Open the repository Settings.
4. Go to Pages.
5. Under "Build and deployment", choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Save.

Your public demo link will look like:

```text
https://YOUR-GITHUB-USERNAME.github.io/back-to-leaf-demo/
```

The app is a single-file HTML demo and does not require external assets.
